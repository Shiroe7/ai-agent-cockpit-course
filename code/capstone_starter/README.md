# 课程项目脚手架

## 推荐选题池

1. 车辆状态问答与故障解释智能体；
2. 驾驶前座舱检查助手；
3. 车载手册检索与操作指导智能体；
4. 多模态座舱 UI 导航助手；
5. 行程规划与能耗解释智能体。

## 必须提交

- 一页问题定义：用户是谁、场景是什么、现有方式为什么不够；
- 工作流图：输入、状态、模型、工具、输出及失败分支；
- 工具或接口契约；
- 数据说明和隐私处理；
- 至少 8 个测试用例；
- 风险清单与高风险操作确认机制；
- 运行日志、演示说明及 Git 提交记录。

## 安全红线

- 不连接真实车辆控制接口；
- 不上传真实 VIN、位置、驾驶轨迹或个人数据；
- 不把模型生成的坐标直接转成真实点击；
- 外部工具返回内容一律视为不可信输入；
- 高风险动作必须人工确认，并保留审计日志。

## 建议目录

```text
project/
├─ README.md
├─ src/
├─ data/
├─ tests/
├─ docs/
└─ runtime/
```
